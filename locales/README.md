# Локализация BoardHack

Строки интерфейса лежат здесь. На страницу подгружается **только выбранный** язык (`ru` или `en`).

## Файлы

- `ru.json` — русский
- `en.json` — английский

Структура каждого файла:

```json
{
  "shared": { "newGame": "Новая игра", "...": "..." },
  "pages": {
    "hub": { "heroDesc": "..." },
    "chess/classic": { "rulesHtml": "..." },
    "chess/custom": { "...": "..." },
    "chess/dice": { "...": "..." },
    "chess/atomic": { "...": "..." },
    "chess/knights": { "...": "..." },
    "chess/three": { "...": "..." },
    "checkers/classic": { "...": "..." },
    "checkers/custom": { "...": "..." }
  }
}
```

- `shared` — общие ключи для нескольких экранов
- `pages.<id>` — строки конкретного экрана (перекрывают `shared` при совпадении ключа)

## Как править

1. Откройте `ru.json` и/или `en.json`.
2. Найдите нужный ключ (поиск по русскому/английскому тексту или по имени ключа).
3. Измените значение. HTML в значениях допустим там, где он уже был (например `rulesHtml`, `heroTitleHtml`).
4. Сохраните файл и залейте на GitHub / обновите Desktop. При необходимости сделайте hard refresh (кэш сбрасывается параметром `?v=` у JSON).

Язык пользователя хранится в `localStorage` под ключом из `js/boardhack-config.js` (`storage.lang`, сейчас `boardhack-lang`, `ru` | `en`), по умолчанию русский.
